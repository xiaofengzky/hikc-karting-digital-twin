# HIKC 孝感卡丁车赛车场 · 数字孪生

一个**单文件、离线可用**的 Three.js 三维场景，还原孝感市奥林匹克体育中心旁的 HIKC 国际卡丁车赛车场及其周边环境。

直接双击 `HIKC_孝感卡丁车赛车场.html` 即可在浏览器中打开，无需服务器、无需联网。

---

## 场景内容

| 模块 | 说明 |
|---|---|
| 赛道 | 中心线取自 VBO 遥测轨迹，全长约 1233m，识别出 17 个弯；路肩蓝白分段铺设 |
| 维修区 | P 房 8 个车库单元（卷帘门朝赛道）、二层观景平台、前方水泥停车区 |
| 建筑 | 控制塔、计时塔、服务车间（含卷帘门）、小卖部（含门窗雨棚）、主入口门架、停车场（42 车位带车位线） |
| 赛道设施 | 起跑门架（HKC 横梁 + 4 颗发车灯）、蓝白隔离墩、轮胎墙、广告横幅、高杆灯 |
| 周边环境 | 王母湖（西侧，含曲折岸线）、湖滨公园（长椅/花坛/观景平台/碎石小径）、奥体中心（拱顶桁架结构）、城南大道与奥体东路 |
| 车辆 | 卡丁车真模（OBJ 量化内联），18 台静态停放 + 1 台绕圈行驶 |

## 交互

- **五种机位**：全景环绕 / 自由漫游 / 主看台 / 单圈巡游 / 跟车穿越（FPV，快捷键 `F`）
- **七种天气**：晴、多云、阴、小雨、暴雨、雪、雾，实时改变天空、光照、湿滑度与抓地力
- **时段调节**：日出到深夜连续过渡
- **实时数据面板**：车速、海拔、坐标、VP 精度、温度、湿度、能见度

## 技术要点

- **单文件交付**：所有 JavaScript、纹理（canvas 程序生成）、车模数据（Int16 量化 + base64）全部内联，约 1.05MB
- **赛道贴合**：凡是沿赛道的地物（路肩、隔离墩、水泥区、广告牌）都用 `trackAt(s)` 采样成条带，而非矩形摆放
- **地形与铺装**：铺装区域先在 `terrainHeight()` 里挖走廊压平，避免草地穿透；地面用有厚度的 Box 而非单层 Plane
- **天气着色器**：自定义天空 shader（渐变 + 云层 fbm + 太阳）、雨雪粒子、湿滑层
- **已知取舍**：湖面是平面 + 地形下挖，水陆交界有轻微锯齿（地形网格 5m 一格所致）

## 目录结构

```
HIKC_孝感卡丁车赛车场.html   # 交付物（单文件，双击打开）
parts/                        # 源码分片，build.py 按顺序拼接成上面的 HTML
  p1_head.html                # HTML 骨架 + UI 样式
  p2_util.js                  # 工具函数（纹理、插值、实例化）
  p2b_state.js                # 全局状态与天气预设
  p3_scene.js                 # 渲染器、天空 shader、光照
  p4_track.js                 # 赛道几何、地形、路面
  p5_trackfx.js               # 护栏、轮胎墙、广告、门架、高杆灯
  p6_buildings.js             # 建筑、卡丁车、停车区
  p7_env.js                   # 道路、湖、公园、树木、城市远景
  p8_weather.js               # 天气与粒子
  p9_camera.js                # 相机与交互
  p10_ui.js                   # 面板、标签、图表
  p11_main.js                 # 装配与主循环
  p12_tail.html               # 收尾
tools/                        # 数据生成与验证脚本（Python / Node）
assets/                       # 原始模型素材
```

改完 `parts/` 里的分片后，执行：

```bash
python parts/build.py   # 重新生成单文件 HTML
```

## 关于数据

赛道中心线来自车载 VBO 遥测（采样点 + 曲率）。原始数据的经纬度不可靠（不在孝感），
因此**环境方位一律以现场指认为准**，未使用 heading 推算。
